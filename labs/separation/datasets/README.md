# Test material

Do not commit commercial audio or private stems here.

Recommended local test fragments are 30-60 seconds and should cover:

- clean bass;
- distorted bass;
- slap/fretless bass;
- bass and kick overlap;
- dense guitars;
- vocals with reverb and backing vocals;
- piano and guitar together;
- heavy cymbals;
- acoustic music;
- electronic sub-bass.

Use authorized datasets when metrics need reference stems. Commercial songs may be used privately for listening tests, but must not be committed or published.
