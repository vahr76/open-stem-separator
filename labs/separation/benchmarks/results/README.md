# Separation benchmark results

This folder stores selected benchmark outputs that shaped OSS decisions. It does not store generated audio because those files can be large and may come from copyrighted sources.

Stored artifacts usually include:

- benchmark `REPORT.md` files;
- objective `MEASUREMENT.md` files;
- run `COMPARISON.md` summaries;
- lab notes in `docs/lab-notes/` when a result affects product direction.

Current documented runs:

- `blur-first-measurements/` and `blur-first-comparison/`: first Demucs direct-vs-cascade checks.
- `lp-lost-on-you/`: first user-selected song benchmark across current Demucs candidates.
