# OSS Downloader Core v0.3.2

Patch release for the experimental `oss-lab` separation command.

## Assets

- `ytd-0.3.2-linux-x64.tar.gz`
- `ytd-0.3.2-windows-x64.zip`

## What changed since v0.3.1

- Fixed packaged `oss-lab` external engine execution by cleaning PyInstaller runtime variables before launching `OSS_LAB_PYTHON`.
- Prevented the frozen app `LD_LIBRARY_PATH` from breaking SSL/HTTPS in the external Python environment used by Demucs and PyTorch.
- Confirmed a real 20-second Demucs `htdemucs` separation from the published package path using an external separation venv.
- Preserved automatic CUDA selection behavior: when PyTorch can use CUDA, `effective_device` becomes `cuda`; otherwise it falls back to `cpu`.

## Validation

- Unit test suite: 71 tests passing.
- Real package test: LP “Lost On You” 20-second excerpt produced `bass.wav`, `drums.wav`, `other.wav` and `vocals.wav`.
