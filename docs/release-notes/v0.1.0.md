# OSS Downloader Core v0.1.0

First public prototype of the OSS downloader core, exposed as the `ytd` command.

## What works

- Interactive `ytd` flow.
- URL prompt with audio, video, or both.
- Best available quality selected automatically for the chosen format.
- Audio formats: original source, WAV, FLAC, MP3 320 kbps.
- Video formats: best available video with audio, or best MP4/M4A combination when available.
- Both mode creates two files: complete video and separate audio.
- Automatic cookie fallback using local browsers when yt-dlp reports session/login/cookie style errors.
- Thumbnails disabled by default so thumbnail failures do not interrupt downloads.
- Safe filenames without visible video ID.
- Project folders using best-effort artist/track detection.
- `metadata.json` per download project.
- User-level installers for Linux, macOS, and Windows.
- `ytd doctor` diagnostics.

## Known limitations

- This is the downloader core, not the full stem-separation app.
- Windows and macOS binary packages still need validation on native systems.
- Artist/track detection is heuristic and can be wrong for third-party uploads.
- Cookie extraction depends on browser profile availability and yt-dlp support.
- MP4 can be lower quality than MKV/WebM if the platform offers better non-MP4 streams.
- WAV/FLAC preserve the selected source without further loss but cannot restore quality missing from the original stream.
