# OSS Downloader Core v0.1.4

This release focuses on Linux package portability.

## Assets

- `ytd-0.1.4-linux-x64.tar.gz`
- `ytd-0.1.4-windows-x64.zip`

## What changed since v0.1.3

- Added a GitHub Actions Linux build on `ubuntu-22.04` so the generic Linux binary is no longer built from a rolling-release desktop by default.
- Added a GLIBC inspection step for the Linux binary and fail the workflow if the requirement is newer than `GLIBC_2.35`.
- Added `docs/LINUX_PORTABILITY.md` with the Fedora/Ubuntu smoke-test procedure.
- Bumped Linux and Windows package names to `0.1.4` so release assets match the tag.

## Why

The previous Linux binary was built on CachyOS/Arch and could require a newer glibc than Fedora, Ubuntu, Debian, or other target distros provide. PyInstaller does not make glibc portable, so public Linux releases need to be built from a deliberately older base.

## Validation

Run from the repository before release:

```sh
python3 -m unittest discover -s tests -v
gh workflow run build-linux.yml --ref main
gh workflow run build-windows.yml --ref main
```

Then test the Linux tarball on Fedora 44 and Ubuntu 26 using `docs/LINUX_PORTABILITY.md`.

## Release type

This is a PATCH release under the project versioning policy because it fixes packaging portability without changing the download feature set.
