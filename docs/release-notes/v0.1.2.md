# OSS Downloader Core v0.1.2

QoL pre-release focused on making the downloader easier to use after a download.

## Release assets

- `ytd-0.1.2-linux-x64.tar.gz`
- `ytd-0.1.2-windows-x64.zip`

## What changed since v0.1.1

- Added `ytd config` to show active configuration, downloads folder, history path and thumbnail mode.
- Added `ytd last` to show the last registered download.
- Added `ytd open` to open the last project folder.
- Added `ytd open downloads` to open the configured downloads folder.
- Added `docs/VERSIONING.md` with the pre-1.0 versioning policy.
- Documented QoL vs product-function version bumps.

## Validation

- Shared core tests pass.
- Linux package should be regenerated from this tag.
- Windows package should be generated by GitHub Actions.
- Windows manual testing is still pending on a real Windows machine.

## Notes

This is a PATCH release under the project versioning policy because it adds QoL commands without changing the core download capability.
