# OSS Downloader Core v0.1.1

Second pre-release of the OSS downloader core, exposed as the `ytd` command.

## Release assets

- `ytd-0.1.1-linux-x64.tar.gz`
- `ytd-0.1.1-windows-x64.zip`

## What changed since v0.1.0

- Added a real Linux PyInstaller binary package.
- Added Linux package `install.sh` and `uninstall.sh`.
- Added package `manifest.json` and `SHA256SUMS.txt`.
- Added isolated configuration support with `--config` and `OSS_CONFIG_DIR`.
- Added local download history with `ytd history`.
- Added Windows package scaffold with user-facing `install.cmd` and `uninstall.cmd`.
- Added GitHub Actions Windows build that creates and verifies the Windows zip.
- Fixed Windows console fallback for non-UTF-8 terminals.
- Fixed path portability tests for Windows short/long temp paths.
- Kept macOS and distro-specific Linux packages deferred until real test environments are available.

## Current validation

Linux package:

- Built locally on CachyOS/Linux.
- Verified SHA-256 checksums.
- Installed and uninstalled from a temporary location.
- Ran `ytd doctor` successfully.
- Tested real YouTube download flow for video + FLAC audio.

Windows package:

- Built on GitHub Actions `windows-latest`.
- Unit tests passed.
- Package inspection passed.
- `ytd.exe doctor` ran successfully in CI.
- Manual testing on a real Windows machine is still pending.

Shared core:

- 41 unit tests pass.
- Supports audio original, WAV, FLAC, MP3 320 kbps, video, and video + separate audio.
- Selects best available quality automatically for the chosen format.
- Keeps thumbnails disabled by default so thumbnail failures do not stop downloads.
- Retries automatically with browser cookies when yt-dlp reports login/cookie/session style errors.
- Stores project metadata under best-effort `artist/track` folders.
- Records download history in `history.jsonl`.

## Known limitations

- This is still the downloader core, not the full stem-separation application.
- Windows package needs manual testing on a real Windows machine.
- macOS package is not available yet.
- Linux `.deb`, `.rpm`, Arch/Manjaro and AppImage packages are deferred.
- Artist/track detection is heuristic and can be wrong for third-party uploads.
- The tool does not grant rights over third-party media; users must only download content they are allowed to use.
