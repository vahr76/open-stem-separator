# OSS Downloader Core v0.2.1

This patch completes the `project.json` foundation by registering downloaded media files in the project manifest.

## Assets

- `ytd-0.2.1-linux-x64.tar.gz`
- `ytd-0.2.1-windows-x64.zip`

## What changed since v0.2.0

- After a successful download, `ytd` scans the project folder for final media files and records them in `project.json["media"]`.
- Media entries include relative path, kind, profile, role, file size and modification time.
- Rerunning registration deduplicates entries by path.
- Existing future fields in `project.json` remain preserved.
- Updated tests for media registration.

## Validation

Run from the repository before release:

```sh
python3 -m unittest discover -s tests -v  # 51 tests
gh workflow run build-linux.yml --ref main
gh workflow run build-windows.yml --ref main
```

## Release type

This is a PATCH release under the project versioning policy because it completes the `v0.2.0` project-manifest behavior without introducing a new product area.
