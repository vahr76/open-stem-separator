# OSS Downloader Core v0.2.2

This patch adds a user-facing project inspection command.

## Assets

- `ytd-0.2.2-linux-x64.tar.gz`
- `ytd-0.2.2-windows-x64.zip`

## What changed since v0.2.1

- Added `ytd project` to show a readable summary for the last OSS project.
- Added `ytd project last` and `ytd project /path/to/project`.
- The summary reads `project.json` and shows identity, source URL, registered media, stems, analysis and lyrics counts.
- Documented the new command in README and CLI reference.

## Validation

Run from the repository before release:

```sh
python3 -m unittest discover -s tests -v  # 54 tests
gh workflow run build-linux.yml --ref main
gh workflow run build-windows.yml --ref main
```

## Release type

This is a PATCH release under the project versioning policy because it adds QoL inspection for the project manifest introduced in `v0.2.0`/`v0.2.1`.
