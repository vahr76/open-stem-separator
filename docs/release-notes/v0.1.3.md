# OSS Downloader Core v0.1.3

QoL pre-release focused on documentation and readable history output.

## Release assets

- `ytd-0.1.3-linux-x64.tar.gz`
- `ytd-0.1.3-windows-x64.zip`

## What changed since v0.1.2

- Added `docs/CLI_REFERENCE.md` with a full command and flag reference.
- Linked the CLI reference from the README.
- Changed `ytd history` to show a readable table by default.
- Added `ytd history --json` for scripts and JSON Lines output.

## Validation

- Shared core tests pass.
- Linux package should be regenerated from this tag.
- Windows package should be generated by GitHub Actions.
- Windows manual testing is still pending on a real Windows machine.

## Notes

This is a PATCH release under the project versioning policy because it improves QoL and documentation without changing the core download capability.
