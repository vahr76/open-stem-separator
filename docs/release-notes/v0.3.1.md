# OSS Downloader Core v0.3.1

Patch release for the experimental separation laboratory introduced in v0.3.0.

## Assets

- `ytd-0.3.1-linux-x64.tar.gz`
- `ytd-0.3.1-windows-x64.zip`

## What changed since v0.3.0

- Fixed packaged `oss-lab` engine execution so Demucs runs through an external Python environment instead of accidentally invoking the frozen `oss-lab` executable as Python.
- Added automatic Demucs device selection: `device: "auto"` now probes PyTorch and uses CUDA when available, otherwise CPU.
- Added `OSS_LAB_DEVICE` override for reproducible runs, including `cuda`, `cuda:0`, `cpu` and `mps`.
- Recorded `requested_device` and `effective_device` in separation stage manifests.
- Added LP “Lost On You” benchmark notes and objective comparison results to the repository documentation.

## Notes

`oss-lab` remains experimental. Heavy ML dependencies such as Demucs and PyTorch are still expected to live in a separate Python environment and are not bundled into the lightweight downloader package.
