# Security policy

Please report security issues privately rather than opening a public issue.

Suggested report content:

- affected version;
- operating system;
- exact command or flow;
- impact;
- reproduction steps;
- whether external URLs, cookies, or local files are involved.

This project does not ask for account credentials. Cookie use is delegated to yt-dlp through `--cookies-from-browser` only after a download fails with an error that indicates cookies/session/login may be required.
